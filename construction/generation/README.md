# construction/generation

This directory contains the materials used to convert cleaned `.rs` source samples into a structured `.jsonl` format for subsequent dataset construction.

## Files

- `input.jsonl`  
  Input file containing normalized code samples collected from the cleaned source datasets under `construction/cleaned/`.  
  Each record is stored in a unified JSONL format for batch processing.

- `reverse.py`  
  Prompt template file defining the system and user prompts used for reverse construction (i.e., generating task descriptions and structured fields from Verus/Rust code).

- `verus_creater.py`  
  Generation script that reads `input.jsonl`, invokes the configured language model, and produces structured outputs in JSONL format.

- `verus_bench.jsonl`  
  Output file generated by the script.  
  Contains synthesized samples such as natural-language descriptions, function signatures, and related metadata.

## Example Usage

Run from the repository root:

`python construction/generation/verus_creater.py --limit 10 --model <model_name>`
