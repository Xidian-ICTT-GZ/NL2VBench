Implement a procedure that mutates a given array of 32-bit integers in place. The procedure receives: (1) a mutable array (the primary array), (2) a second mutable array (the auxiliary array), and (3) a 32-bit integer input value. Assume the input value is positive and strictly less than 1000, the initial length of the primary array equals the input value, and the auxiliary array has length exactly 1. After the procedure returns, every element of the primary array must be overwritten to the value equal to (input value + 1). The procedure must not change the length of the primary array, and the auxiliary array must remain of length 1. Formally, for every index k with 0 <= k < input value, the element at index k in the primary array equals (input value + 1).
