Implement a function that conditionally constructs an optional linear algebra error value based on a boolean flag, an error code, and a message string. The function must satisfy the following property: if the boolean flag is true, it returns a non-empty optional value (i.e., Some(error)); if the boolean flag is false, it returns None. When returning Some(error), the error variant is determined by the numeric code (an 8-bit unsigned integer) as follows: 0 maps to NonConvergence, 1 maps to SingularMatrix, 2 maps to NonSquareMatrix, 3 maps to IncompatibleDimensions, 4 maps to InvalidInput, 5 maps to NumericalInstability, and any other code maps to Other. The message string must be attached to the chosen error variant. There are no additional input constraints.
fn select_error(error_variant: u8, message: String) -> LinAlgError
fn check_lin_alg_error(condition: bool, error_variant: u8, message: String) -> (result: Option<LinAlgError>)
