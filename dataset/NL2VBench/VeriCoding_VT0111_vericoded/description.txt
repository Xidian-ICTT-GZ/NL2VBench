Implement two functions that produce a predefined single-precision floating-point sentinel representing positive infinity. The first function returns the constant value 1.0e39 as an f32. The second function must return the same value by calling the first function. There are no inputs. Both functions must guarantee, via their postconditions, that the returned value is exactly 1.0e39f32 (which evaluates to positive infinity in IEEE-754 f32).
fn infinity_f32() -> f32
fn inf() -> f32
