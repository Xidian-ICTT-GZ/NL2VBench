Given two non-negative 64-bit unsigned integers, implement a function that returns the larger of the two values. The function must be verified to satisfy the postcondition that its result equals the mathematical maximum of the two inputs. The solution should use a loop with the following invariants: (1) both working copies of the inputs remain non-negative, (2) an auxiliary counter equals the amount subtracted from each working copy, and (3) the amounts subtracted from the two working copies are equal throughout the loop. The loop must be proven to terminate by providing a measure that strictly decreases on every iteration. There are no preconditions beyond the standard bounds of 64-bit unsigned integers.
spec fn max(x: u64, y: u64) -> u64
fn slow_max(a: u64, b: u64) -> (z: u64)
