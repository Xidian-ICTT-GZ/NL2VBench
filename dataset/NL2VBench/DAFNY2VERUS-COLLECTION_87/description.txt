Implement a function that takes an array of 32-bit signed integers and returns a new array containing the absolute value of each element. Assume the input length is strictly less than 1,000,000. Additionally, assume no element in the input is equal to the minimum 32-bit signed integer (-2147483648), so that taking the absolute value does not overflow when cast back to 32-bit signed integers. The output array must have the same length as the input, and for every valid index, the output’s element equals the mathematical absolute value of the corresponding input element (interpreted as an unbounded integer) cast to a 32-bit signed integer. The relative order of elements must be preserved.
