You are given an integer x (1 ≤ x ≤ 9999) that is guaranteed to be a "boring apartment number": it consists of a single decimal digit d (1 ≤ d ≤ 9) repeated k times, where 1 ≤ k ≤ 4. Consider the ordered list of all boring apartment numbers constructed as follows: for each digit d from 1 to 9 in increasing order, list the numbers d, dd, ddd, dddd (i.e., lengths 1, then 2, then 3, then 4). Typing any number of length k requires exactly k button presses of that digit. Define the score of x as the total number of button presses needed to type, in this order, every boring apartment number from the start of the list up to and including x. Compute and return this score. The input is guaranteed to satisfy the above constraints (x is boring and within the stated range), so no validation is required.
fn solve(x: i32) -> (result: i32)
