You are given a matrix of 8-bit signed integers represented as a vector of rows. Assume the matrix has exactly n rows (n > 0), and each row has exactly m columns. Construct and return a new matrix that stacks the original columns as rows; equivalently, return the transpose of the input matrix. The output must contain exactly m rows, each of length n, and for every valid row index i (0 <= i < n) and column index j (0 <= j < m), the element at position (j, i) in the output must equal the element at position (i, j) in the input. The total number of elements in the output must be m * n.
fn get_column(input: &Vec<Vec<i8>>, j: usize, m: usize, n: usize) -> (col: Vec<i8>)
fn column_stack(input: Vec<Vec<i8>>, m: usize, n: usize) -> (result: Vec<Vec<i8>>)
