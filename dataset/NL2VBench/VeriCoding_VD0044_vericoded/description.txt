Implement a function that takes a read-only integer array and an integer value, and returns a new array equal to the original array with the value appended at the end. The input array must not be modified. The returned array must preserve the exact order of elements from the input and then have the given value as the final element. Formally, the output sequence must be equal to the concatenation of the input sequence with a single-element sequence containing the provided value. There are no additional preconditions. If the input array is empty, the result is a single-element array containing the provided value.
fn append(a: &Vec<i32>, b: i32) -> Vec<i32>
