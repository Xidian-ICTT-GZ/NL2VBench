- '5' -> 4
- '6' -> 2
- '7' -> 5
- '8' -> 1
- '9' -> 2

Return a new character array that is the standard decimal representation of this product (without leading zeros) followed by a newline character. The output must contain only digit characters and the trailing newline, and its last character must be a newline.
