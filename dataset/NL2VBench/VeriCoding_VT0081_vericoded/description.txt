Implement a function that takes two arrays of 32-bit floating-point numbers of equal length and returns a two-row matrix (a vector of vectors) formed by stacking the two input arrays vertically. Assume the input arrays have the same length. The returned matrix must satisfy the following properties: it has exactly two rows; the length of the first row equals the length of the first input array; the length of the second row equals the length of the second input array; for every valid index within the common length, the element at that index in the first row is equal to the corresponding element in the first input array, and the element at that index in the second row is equal to the corresponding element in the second input array.
fn vstack(a: Vec<f32>, b: Vec<f32>) -> (result: Vec<Vec<f32>>)
fn make_outer(a: Vec<f32>, b: Vec<f32>) -> (result: Vec<Vec<f32>>)
