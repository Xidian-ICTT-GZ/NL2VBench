Implement a function that takes a vector and an axis indicator. The axis is a non-negative integer that must be at most 1. The function returns a tagged wrapper indicating whether the vector is being treated as a row or as a column. Specifically: if the axis is 0, the function must return a row-vector wrapper containing exactly the same elements, in the same order, as the input vector; if the axis is 1, the function must return a column-vector wrapper containing exactly the same elements, in the same order, as the input vector. Under the assumption that the axis is at most 1, any axis value that is not 0 must be 1.
pub enum ExpandedVector<T> { RowVector(Vec<T>), ColumnVector(Vec<T>) }
fn expand_dims<T>(a: Vec<T>, axis: usize) -> ExpandedVector<T>
