- digit2
- operator2 ('+' or '-')
- digit3
- operator3 ('+' or '-')
- digit4
- '='
- '7'
- '\n'

The digits in the output must be exactly the four input digits in the same order. Each operator must be either '+' or '-'. The expression formed by these digits and operators must evaluate to 7. If multiple solutions exist, returning any one valid expression is acceptable. Do not reorder or modify the digits; only choose the operators.
