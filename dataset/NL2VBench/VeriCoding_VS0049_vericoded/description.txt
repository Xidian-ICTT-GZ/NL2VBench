Given an array of 32-bit signed integers, produce a new array of the same length where each element is replaced by its sign. For each position i in the input, the corresponding output element must be: 1 if the input element is strictly positive, 0 if the input element is zero, and -1 if the input element is strictly negative. The relative order of elements must be preserved, and the output length must equal the input length. The input may be empty.
fn sign_of(x: i32) -> (r: i32)
fn sign(a: Vec<i32>) -> (result: Vec<i32>)
