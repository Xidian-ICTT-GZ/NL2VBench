Assumptions:
- The input length is exactly 3.
- Every character in the input is either 'A' or 'B'.
Required properties:
- The output is "Yes" if and only if there exists an index i in {0, 1} such that input[i] != input[i+1].
- The output must be exactly one of the two strings: "Yes" or "No".
