Given a vector of characters, compute how many of those characters are ASCII decimal digits. A character is considered a decimal digit if its code lies between the ASCII codes of '0' and '9' inclusive (i.e., 48 through 57). The input may be empty.
Return the count as a nonnegative integer not exceeding the input length. The result must equal the mathematically defined count obtained by recursively processing the sequence: the count on an empty sequence is 0; otherwise, it is the count on the sequence without its last element plus 1 if the last element is a digit, and unchanged if the last element is not a digit.
fn count_digits(text: &Vec<char>) -> (count: usize)
