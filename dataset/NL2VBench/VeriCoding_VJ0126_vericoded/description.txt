You are given an array of non-negative integers (unsigned machine-sized integers). Determine whether the array satisfies the following property: for every valid index, the element stored at that index has the same parity as the index itself. Equivalently, every even index contains an even number and every odd index contains an odd number. The array may be empty; in that case, the property is considered satisfied. Return true if and only if the property holds for all indices in the array; otherwise, return false.
