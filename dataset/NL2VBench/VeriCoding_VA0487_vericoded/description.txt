The truth table is as follows: 1 → 1, 2 → 0, 3 → 0, 4 → 1, 5 → 0, 6 → 1, 7 → 0, 8 → 1, 9 → 1, 10 → 1, 11 → 0, 12 → 0, 13 → 1, 14 → 0, 15 → 1, 16 → 0.
fn solve(n: i8) -> (result: i8)
