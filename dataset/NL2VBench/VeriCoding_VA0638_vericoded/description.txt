The input is guaranteed to follow one of two formats: either exactly three characters [X, ' ', Y], or exactly four characters [X, ' ', Y, '\n'], where X and Y are both valid uppercase hexadecimal letters from A to F. Assume the input size is at least 3, the separator at index 1 is a space, and if a fourth character is present, it is a newline. The output must be a two-character array consisting of one of the symbols '<', '>', or '=', followed by a newline character. The symbol must reflect the standard character ordering comparison of the first letter against the second letter: '<' if the first letter is less than the second, '>' if greater, and '=' if they are equal.
