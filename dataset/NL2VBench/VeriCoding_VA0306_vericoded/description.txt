Assume the input length is at least one. The returned array must have exactly the same length as the input. During the construction, maintain the property that for every index within the already-constructed prefix, the output character at that index equals the corresponding input character. The loop must be proven to terminate using a strictly decreasing measure equal to the number of elements left to process.
