Given an integer n, construct a vector containing the first n Fibonacci numbers using signed 32-bit integers. Assume n is at least 2. Additionally, assume the mathematical Fibonacci number at index n is strictly less than 2^31, ensuring that all sequence values up to index n fit in a signed 32-bit integer. The output vector must have length n. The sequence is defined by F(0) = 0, F(1) = 1, and for all indices i in the range [2, n), F(i) = F(i−1) + F(i−2). For every index i in [2, n), the i-th element of the output equals the mathematical Fibonacci number at index i.
fn fibonacci(n: usize) -> (ret: Vec<i32>)
