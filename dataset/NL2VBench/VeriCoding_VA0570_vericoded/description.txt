You are given a forecast for exactly three consecutive days. Each day is represented by a character that is either 'R' (rainy) or 'S' (sunny). Assume the input length is exactly three and every character is either 'R' or 'S'. Determine the maximum number of consecutive rainy days within these three days and return that length as an integer. The result must be between 0 and 3, inclusive. If there are no rainy days, return 0. If there is at least one rainy day but no two adjacent rainy days, return 1. If there is at least one pair of adjacent rainy days, return 2. If all three days are rainy, return 3. Inputs that do not satisfy the assumptions are out of scope.
fn solve(input: Vec<char>) -> (result: i8)
